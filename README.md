# My Bible App

This repository contains a scaffold for an Expo + React Native (TypeScript) mobile app that displays Bible verses and a simple chat prototype UI.

What's included:
- App.tsx (font loader + navigation)
- screens/BibleScreen.tsx
- components/VerseRow.tsx
- assets/fonts/ (placeholder)

To run locally:
1. Install Node.js (LTS) and npm.
2. Clone this repo and cd into it:
   git clone https://github.com/nathanjtmhungu22-lab/-my-bible-app.git
   cd -my-bible-app
3. Install dependencies and start Expo:
   npm install
   npx expo start

You will still need to run `npx create-expo-app` locally if you prefer a full working package.json and Expo setup. This scaffold focuses on source files for the UI.
